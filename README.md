# 🎉 Event Management Dashboard

An interactive and responsive dashboard designed to streamline event financial tracking, enabling organizers to easily monitor funds collected, spent, and remaining.

---

## 📌 Project Description

The **Event Management Dashboard** is a web-based application developed to efficiently manage and display event-related financial data. It provides a real-time visual representation of the **total amount collected**, **amount spent**, and **amount left**, making it easier for organizers to stay on top of their event budget.

Developed using **HTML, CSS, JavaScript**, and **Bootstrap**, this dashboard offers a modern UI and ensures a seamless user experience across devices through responsive design techniques.

---

## ✨ Key Features

- **Dynamic UI** to display event metrics like:
  - Total amount collected
  - Amount spent
  - Amount left
- **Responsive layout** adaptable to mobile, tablet, and desktop views
- **Real-time data updates** using JavaScript
- **Clean and aesthetic interface** for intuitive interaction
- **Easy data integration** using JSON or external sources like Google Sheets
- **Bootstrap-powered components** for fast and consistent styling
